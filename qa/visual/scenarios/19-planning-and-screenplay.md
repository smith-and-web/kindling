# 19 Planning, discovery notes and screenplay

Manual extension; not yet an executable socket suite. Use owned disposable
novel and screenplay projects. Capture each distinct surface in light/dark at
1600×1000 and light at 1100×700; include q.audit(), q.axe(), q.overflow() and errors.

1. Switch scenes among Fixed, Flexible and Undefined. Verify the available prose,
   outline prompts, planned/next filters, status badges and empty states agree.
2. Expand discovery notes; edit/save, navigate/reopen and verify retention. Check
   the collapsed hint, keyboard hint and long-note scrolling at narrow width.
3. Create a screenplay and inspect scene heading, action, character, parenthetical,
   dialogue and transition elements, including keyboard navigation and wrapping.
4. Check screenplay Page view, word/page counts and project page target. Changing
   unified settings must preserve the existing screenplay page target.
5. Inspect template browsing/selection and create from a template. Verify applying
   it affects only the project created by this run.
6. Export screenplay/treatment into the run folder and inspect the actual output,
   including part/chapter order, page breaks, Unicode and long dialogue. A dialog
   screenshot alone does not establish export correctness.
